# 💰 Personal Expense Tracker

A simple command-line **Expense Tracker built with Python** that allows users to record, categorize, and manage their daily expenses.

## 🚀 Features

- ➕ Add new expenses
- 🏷️ Categorize expenses
  - Food
  - Travel
  - Shopping
  - Bills
  - Other
- 📋 View all recorded expenses
- 💵 Calculate total spending
- ⚠️ Handles invalid menu choices
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- **Python 3**
- **Dictionaries**
- **Lists**
- **Loops**
- **Conditional Statements**
- **User Input**
